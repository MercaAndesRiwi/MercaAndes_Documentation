# Welcome to MercaAndes

**MercaAndes** is a data project focused on integrating and processing sales information in a multinational omnichannel environment.

The project aims to organize sales data from different sources and countries, providing a foundation for data processing and analysis.

## Project Scope

MercaAndes covers sales data associated with the following countries:

- Colombia
- Peru
- Ecuador
- Bolivia
- Chile
- Brazil, considered within the project's historical context.

The project focuses on organizing and processing sales data while accounting for the specific characteristics of each country's data.

## Main Components

The project includes several components that support data management and processing:

- **Data Sources and Simulators:** provide source data and generate simulated commercial information.
- **Databases:** organize sales information using country-specific schemas.
- **Data Processing:** supports the preparation and transformation of data.
- **Services and APIs:** provide interfaces for accessing and managing project data.
- **Infrastructure and Orchestration:** support the execution and coordination of project components.

The implementation details of each component are described in their respective sections.
