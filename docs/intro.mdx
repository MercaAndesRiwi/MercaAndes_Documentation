# Bienvenido a MercaAndes

MercaAndes es un proyecto orientado a la integración y procesamiento de datos de ventas de diferentes países.

## Sobre esta documentación

En este sitio encontrarás información sobre el proyecto, su arquitectura, modelo de datos, procesos de procesamiento y configuración técnica.

El objetivo es centralizar la información necesaria para comprender el funcionamiento del sistema y facilitar su desarrollo y mantenimiento.
