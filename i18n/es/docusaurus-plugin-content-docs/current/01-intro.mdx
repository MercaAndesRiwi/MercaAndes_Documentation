# Bienvenido a MercaAndes

**MercaAndes** es una plataforma de datos para integrar y procesar información de ventas e inventario en una operación retail omnicanal y multipaís.

El proyecto busca organizar datos procedentes de varios canales y países para facilitar su procesamiento y análisis.

## Alcance del proyecto

La plataforma considera los siguientes países:

- Colombia
- Perú
- Ecuador
- Bolivia
- Chile
- Brasil, dentro del contexto histórico del proyecto

El alcance contempla la organización y el procesamiento de datos comerciales, teniendo en cuenta las particularidades de cada país.

## Componentes principales

El proyecto reúne componentes que respaldan la gestión y el procesamiento de datos:

- **Fuentes y simuladores de datos:** aportan datos de origen y generan información comercial simulada.
- **Bases de datos:** organizan la información de ventas y los esquemas específicos por país.
- **Procesamiento de datos:** prepara, valida y transforma los datos.
- **Servicios y APIs:** ofrecen interfaces para consultar o gestionar información del proyecto.
- **Infraestructura y orquestación:** despliegan y coordinan los componentes.

Las secciones correspondientes describen cada componente con mayor detalle.

## Acerca de esta documentación

Esta documentación reúne la información necesaria para entender, desplegar y mantener MercaAndes. Está dirigida a las personas que participan en el desarrollo y la operación técnica del proyecto.

El contenido se organiza en guías de despliegue, arquitectura, bases de datos, procesamiento, servicios y prácticas de desarrollo. Las páginas de AWS describen la infraestructura y los servicios que componen la plataforma.
